# v0.16.0 — Target Awareness & Fault Diagnostics

The original planning discussion assigned these capabilities to v0.15.2. The v0.15.2 number is now consumed by the Interactive Debug lifecycle hotfix, so feature development moves to v0.16.0 rather than mixing a field hotfix with a debugger expansion.

## Identity

B300 remains an engineering Flash + Remote Debug + Realtime Diagnostic Workstation for STM32 robots. It is not intended to clone STM32CubeIDE.

## Frozen safety boundaries

- Normal Flash remains Application S4-S7 only; protected Bootloader S0-S2 is unchanged.
- OTA metadata and Option Bytes policy are unchanged.
- Live Monitor remains zero-halt/read-only and must never borrow HALT-based inspectors.
- Peripheral inspection is read-only and HALT-only.
- Fault analysis never resets, resumes, or mutates the target.
- GDB/TCL transport and loopback policy are unchanged.
- Gateway remains transport infrastructure; target interpretation stays on the engineering side.

## Milestone dependency order

1. TargetDescription / TargetRegistry for STM32F407ZE.
2. CMSIS-SVD model + bounded loader + lazy read-only PeripheralService.
3. Cortex-M HardFault decoder + exception frame reconstruction.
4. Workstation integration for Local and Client parity.
5. DWARF type provider foundation.
6. FreeRTOS Task Inspector without hard-coded kernel structure offsets.
7. GUI panes: Target, Peripherals, FreeRTOS, Fault.
8. Full regression + hardware acceptance.

## Phase 1 implemented on feature branch

- `b300_core/target/*`: explicit STM32F407ZE target profile and memory/capability map.
- `b300_core/peripheral/*`: transport-neutral SVD models, bounded XML loader, lazy HALT-only register reads, field decoding, no write primitive.
- `b300_core/fault/*`: CFSR/HFSR decoding, BFAR/MMFAR selection, MSP/PSP + EXC_RETURN exception frame reconstruction, no target state changes.
- `b300_core/target_awareness.py`: GUI-neutral facade that attaches to existing DebugWorkspace/DebugMemory backends without changing v0.15.x lifecycle code.
- `tests/test_target_awareness.py`: regression coverage for target map, SVD bitfields, fail-closed address validation, and Cortex-M fault reconstruction.

## Explicitly deferred

SWO/ITM, RTT, trace timeline, profiling, code coverage, peripheral writes, arbitrary memory writes, Queue/Semaphore/Timer viewers, J-Link, and STM32H7 are not part of the first target-awareness slice.
