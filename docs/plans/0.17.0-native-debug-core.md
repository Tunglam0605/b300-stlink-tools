# B300 ST-Link Tools v0.17.0 — Native Debug Core Foundation

## Mục tiêu

Phát triển song song một native C++ core cho các hot path hiệu năng cao mà không rewrite control-plane Python/PySide6 hiện tại. Nhánh native phải có thể tiến hóa độc lập, sau đó tích hợp vào một integration branch sau khi v0.16.0 debugger intelligence ổn định.

## Ranh giới kiến trúc

Python tiếp tục sở hữu:
- PySide6 GUI và Qt main-thread lifecycle.
- Flash/OTA/Bootloader/metadata/Option Bytes safety policy.
- HardwareSession lock và target-state restoration.
- OpenOCD/GDB/SSH orchestration.
- SVD/Peripheral Inspector, FreeRTOS Inspector và Fault Analyzer ở tần số thấp.
- Update/release/install/support workflows.

C++ native core chỉ sở hữu data-plane hiệu năng cao:
- trace/event capture model;
- bounded ring buffers;
- timestamp/event normalization;
- high-rate sampling transport-neutral primitives;
- decoder hot paths và benchmark instrumentation.

C++ không được:
- sở hữu QWidget/QObject GUI;
- flash/erase target;
- đổi RDP/WRP/Option Bytes;
- expose raw GDB/TCL console;
- quyết định halt/reset/resume policy;
- bypass Python safety/session interlocks.

## Contract-first integration

Native core phải độc lập với Python binding. Public C++ API nằm dưới `native/b300_debug_core/include/b300/` và không include pybind11/Python/Qt. Binding layer về sau nằm riêng tại `native/b300_debug_core/bindings/python/`.

Data contract v1:
- `TraceEvent`: monotonic timestamp, source, channel, type, payload/value.
- `SamplePoint`: monotonic timestamp, numeric channel id, raw 64-bit value.
- Bounded queues report dropped-item counters explicitly; không block realtime producer vô hạn.
- API read/drain phải bounded theo `max_items`.

## Branch strategy

- `feature/v0.16.0-target-awareness-phase1`: Python debugger intelligence (SVD, DWARF, FreeRTOS, Fault, GUI).
- `feature/v0.17-native-core-foundation`: C++ native core, benchmark, native-only CI.
- `integration/v0.17-native-core`: tạo sau khi v0.16.0 ổn định; hợp nhất hai dòng phát triển.

Hai feature branch tránh sửa cùng file. Native branch không sửa `b300_gui/*`, Flash/OTA modules hay existing release workflow trong giai đoạn foundation. Nếu cần CI, dùng workflow native riêng.

## Integration sequence

1. Hoàn thiện và phát hành v0.16.0 bằng Python path.
2. Đồng bộ native branch lên commit v0.16.0 đã xác minh.
3. Tạo integration branch.
4. Thêm pybind11 adapter mỏng, không đưa policy vào binding.
5. Thêm `NativeDebugCoreAdapter` phía Python với mode `auto/off/on` và Python fallback.
6. Chạy parity tests: cùng input vector phải cho cùng event/sample output.
7. Chạy performance gates; chỉ bật native mặc định nếu có lợi ích đo được.
8. Build Windows x64, Ubuntu x64, Ubuntu ARM64; packaged smoke test có native library.
9. Hardware acceptance rồi mới phát hành v0.17.0.

## Performance gates ban đầu

Native path chỉ được bật mặc định khi đạt đồng thời:
- không mất dữ liệu ngoài bounded drop policy;
- không làm tăng target halt/resume activity;
- producer không block vô hạn;
- throughput >= 50k synthetic events/s trên CI reference benchmark hoặc nhanh hơn Python reference >= 3x;
- bounded memory usage theo configured capacity;
- shutdown/join hữu hạn, không treo Qt/PyInstaller process.

Các ngưỡng thực tế sẽ điều chỉnh sau khi có SWO/ITM/RTT hardware measurements.

## Không tối ưu sớm

v0.16 Live Monitor 10 Hz, SVD, FreeRTOS và Fault logic vẫn ưu tiên Python. Chỉ migrate hot path sau khi benchmark/profiling chứng minh bottleneck. DWARF có thể dùng GDB/pyelftools/libdw/LLVM adapter tùy nhu cầu; không tự viết parser DWARF hoàn chỉnh từ đầu.
