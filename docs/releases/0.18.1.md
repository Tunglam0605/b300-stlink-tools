# B300 ST-Link Tools v0.18.1

Patch release for the existing v0.18 workflow. It fixes implementation
gaps and upgrade corruption risks without introducing a new public GUI or CLI
workflow. Release status remains gated by exact-SHA verification.

## User-visible changes

- PROGRAM, MONITOR, DEBUG, DEVICE and SETTINGS remain the production pages.
- Monitor owns its lifecycle independently; the hidden legacy debug workbench is
  no longer constructed for production.
- VS Code and Cortex-Debug own interactive source debugging. B300 owns probe,
  OpenOCD, managed GDB, SSH and bridge cleanup. Updating B300 launch settings
  preserves unrelated configurations.
- CLI and agent guidance use consistent LOCAL / GATEWAY / CLIENT roles.
- Windows installers stage and verify the new runtime before replacing owned
  paths, restore the complete previous owned runtime on handled failures, and
  remove stale runtime files after successful upgrades. User data outside the
  declared owned paths is preserved.
- Native bundles carry a versioned SHA-256 manifest of the complete runtime.

## Installer ownership and recovery

`_internal`, `vendor`, `resources/firmware`, the GUI executable, publisher branding,
LICENSE, install.ps1 and bundle/runtime metadata are publisher-owned. User
profiles, logs, caches and other files outside those paths are not swept.

The installer retains `.b300-upgrade-rollback` until the transaction completes.
A process kill or power loss may prevent automatic recovery; an existing backup
blocks further installation and must be recovered before retrying. Do not delete
an unexamined backup. This is not a claim of power-loss-proof atomic publication.

## Hardware

HW-P1-001 remains open. B300 APPLICATION ACCEPTANCE: **DEFERRED**. Prior STM32F4
Discovery local-debug evidence does not establish B300 Application acceptance or
the remote Gateway connection shown in the current incident screenshots.

Flash sectors, Bootloader protection, metadata verification and Factory guards
remain unchanged. No new board flash is part of installer validation.
