# B300 ST-Link Tools v0.23.1

v0.23.1 is a Gateway Agent startup hotfix for v0.23.0.

## Gateway Agent startup

- The packaged `debug gateway-agent` entry point now imports and acquires its single-owner lock correctly on Windows and Linux.
- Release workflows start the packaged Gateway Agent and require it to remain alive, covering the exact runtime path used by the user service.

## Linux CLI upgrades

- Managed Linux CLI self-update now installs the bundled `b300-stlink-gateway-agent.service` unit under the current user's systemd directory.
- Upgrades from releases that predate the Gateway Agent can therefore complete `gateway quickstart --confirm-system-change` without copying the unit manually.

GDB and TCL remain loopback-only. This hotfix does not change flash, erase, RDP, WRP or Option Byte behavior.
