# B300 ST-Link Tools v0.18.2

Fixes the v0.18.1 packaging omission that prevented Live Monitor from reading
AXF/ELF symbols on a machine without a separate GNU Arm toolchain. The managed
runtime now includes nm, addr2line and objdump on Windows, Ubuntu x64 and ARM64.
Builds fail when a required tool is absent or cannot execute.

VS Code and Cortex-Debug installation remains manual. B300 prepares the debug
configuration and opens the workspace; the user starts debugging with F5.

Offline validation with the supplied AXF resolved 1,691 symbols, xTickCount and
a source location. This does not establish a live Monitor hardware acceptance
result. No hardware was accessed for this fix; HW-P1-001 remains open and B300
APPLICATION ACCEPTANCE is DEFERRED.
