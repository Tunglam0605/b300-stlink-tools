# B300 ST-Link Tools v0.19.0

v0.19.0 consolidates the v0.18 production workflow so shared resources are configured once instead of being re-entered on several pages.

## Shared resources

- **Gateway Manager:** save multiple named Gateway endpoints, choose a default, connect/disconnect and reuse one authenticated SSH session across Monitor and Debug. Only name/host/user/port are persisted. Passwords are process-memory only and are cleared when B300 closes.
- **Debug Project Manager:** save a workspace together with its matching ELF/AXF. Monitor and Debug Local/Client select the same project profile.
- The legacy single Gateway profile is migrated into the new store and the selected default remains synchronized for CLI compatibility.

## Simplified production UI

- PROGRAM: Application/Factory programming only; duplicate Target/refresh actions are hidden.
- MONITOR: Local/Client + Project, and Gateway only for Client; the duplicate ELF/AXF picker is removed from the visible workflow.
- DEBUG: Local/Gateway/Client each have one primary action; advanced connection/environment diagnostics remain collapsible.
- DEVICE: canonical Target inspection and hardware evidence.
- SETTINGS: canonical owner for Gateway/Project management, machine setup, theme, updates and support actions.

## Safety and acceptance

No normal flash/Factory safety contract is weakened. HardwareSession arbitration, zero-halt Monitor behavior, loopback-only OpenOCD exposure and fail-closed remote programming remain intact. This software release does not close `HW-P1-001`; B300 APPLICATION ACCEPTANCE remains DEFERRED until physical-device validation provides new evidence.
