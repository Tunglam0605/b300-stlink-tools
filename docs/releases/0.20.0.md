# B300 ST-Link Tools v0.20.0

v0.20.0 introduces the unified Vietnamese engineering workspace for programming, monitoring, VS Code debugging, Target inspection and shared setup.

## Unified production workspace

- PROGRAM, MONITOR, DEBUG, DEVICE and SETTINGS now share the selected project, ST-Link probe, Target evidence and operation state.
- Saved project profiles include workspace, ELF/AXF, Application HEX and expected Target family, with automatic migration from the previous schema.
- PROGRAM uses the selected project's HEX by default and retains an explicit per-session override.

## Engineering interface

- The five production pages use a consistent dense engineering-console layout with responsive cards, restrained industrial branding and compact technical icons.
- Production labels, actions, status text and dialogs are presented in Vietnamese.
- MONITOR includes a live-variable table, recent samples and trend display while keeping zero-halt sampling behavior.
- DEBUG remains an attach-only VS Code/Cortex-Debug workflow; DEVICE remains read-only.

## Safety and acceptance

The canonical Application and Factory programming paths are unchanged. Normal Application programming still protects Bootloader sectors S0-S2, cannot mass erase, validates Target/WRP/RDP/FlashPlan evidence and uses the existing confirmation and metadata transaction. No Option Bytes or RDP behavior is relaxed. `HW-P1-001` remains **OPEN / DEFERRED**; this software release does not claim new physical-board acceptance.
