# B300 ST-Link Tools v0.19.1

v0.19.1 is a focused PROGRAM preflight and state-consistency patch on top of v0.19.0.

## PROGRAM preflight

- **NẠP APPLICATION** now performs a fresh read-only Target preflight automatically before the existing confirmation and canonical flash transaction.
- The preflight reads and validates target identity, flash size, Bootloader WRP S0-S2, RDP and the current HEX/FlashPlan.
- Unsafe or incomplete evidence blocks before erase/program. No flash safety rule is relaxed.

## State and UX consistency

- PROGRAM, DEVICE and the top status cards render the same `TargetInfo` evidence.
- `Chưa kiểm tra` is neutral/pending; only an actual failed check is shown as an error.
- Probe/HEX/context changes invalidate stale inspection evidence so a previous PASS cannot authorize a new operation.
- DEVICE remains the only page with the explicit **Kiểm tra Target** action; PROGRAM consumes the same read-only inspection backend without duplicating that control.

## Safety and acceptance

The underlying Application flash transaction is unchanged: normal flow still protects Bootloader sectors S0-S2, preserves fail-closed WRP/RDP/target checks and only proceeds to reset/run after the canonical metadata transaction succeeds. `HW-P1-001` remains **OPEN / DEFERRED**; this software patch does not establish new physical-board acceptance.
