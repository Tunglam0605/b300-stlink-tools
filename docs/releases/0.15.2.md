# B300 ST-Link Tools v0.15.2

## Debug Studio lifecycle fix

- Fixed the Interactive Debug transition that could reparent the normal zero-halt realtime monitor into the Engineering Workstation.
- Interactive Debug now opens its workstation without taking ownership of the realtime monitor widget.
- Disconnect returns to the normal Debug Studio with the realtime monitor still present and usable.
- Added a defensive recovery path that restores the realtime panel to its original Studio layout if legacy/accidental reparenting is detected.

## UI stability

- Removes the Qt layout ownership conflict that could produce broken frames/geometry after entering Interactive Debug.
- The Interactive Workstation now shows a clear boundary notice instead of embedding the realtime monitor in its lower dock.
- Realtime monitoring and Interactive Debug remain visually and lifecycle-separated so the operator can tell which path may HALT the MCU.

## Safety unchanged

- No change to Flash/OTA/Bootloader/metadata/Option Bytes policy.
- No change to protected Sector 0–2 behavior.
- GDB/TCL remain loopback-only.
- Realtime Live Monitor remains zero-halt/read-only and must not disturb the realtime robot loop.
- Interactive Debug remains HALT-capable by design and target-state restoration behavior is unchanged.
