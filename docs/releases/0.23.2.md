# B300 ST-Link Tools v0.23.2

v0.23.2 fixes a false `Gateway is busy` state that could remain after a remote lease reservation failed before OpenOCD ever started.

## Gateway lease recovery

- A no-probe reservation is released when the supervisor is stopped and no private OpenOCD owner record was ever created.
- A persisted recovery lease from that same case is reconciled after Agent restart.
- Malformed, unreadable, mismatched or uncertain owner evidence remains fail-closed and continues to require recovery proof.

## Remote GUI status

- The shared context bar now shows authenticated Gateway Agent/lease state when legacy Gateway status reports `STOPPED`.
- Transport failures immediately clear Agent/lease evidence, preventing stale ownership from being displayed.
- A stopped legacy Gateway remains ineligible for debug attach; this change only corrects the status presentation.

GDB and TCL remain loopback-only. No flash, erase, RDP, WRP or Option Byte behavior changed.
