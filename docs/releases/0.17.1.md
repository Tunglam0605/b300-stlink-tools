# B300 ST-Link Tools v0.17.1

## Debug IDE is now a first-class Studio surface

- Opens the dockable Keil/STM-Studio-style Debug IDE shell directly when entering the engineering Debug Studio; opening the IDE does **not** attach, halt, reset, or otherwise change the STM32 target state.
- Adds an always-visible Studio view switch so engineers can move explicitly between **Debug IDE** and **Theo dõi realtime** instead of discovering Interactive Debug through a collapsed advanced card.
- Adds explicit **Kết nối Debug** and **Kết nối / Cấu hình** controls to the IDE surface. Interactive attach remains a separate deliberate action and continues to use the existing LOCAL/CLIENT connection lifecycle.
- Keeps the zero-halt Live Monitor on the normal Studio page and never reparents it into the HALT-capable IDE workstation.

## Safety boundaries unchanged

- Merely opening or viewing Debug IDE is presentation-only and must not start GDB/OpenOCD, acquire the hardware session, halt the MCU, reset the target, or modify flash.
- Interactive Debug may halt/reset/step only after the user explicitly starts a debug connection.
- Normal programming still protects Bootloader Sector 0–2; metadata/OTA/Option Bytes policy is unchanged.
- Integrated GDB/TCL endpoints remain loopback-only, with existing target-state restoration and HardwareSession ownership unchanged.
