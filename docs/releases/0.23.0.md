# B300 ST-Link Tools v0.23.0

v0.23.0 adds exclusive remote Gateway leases for Live Monitor and VS Code debugging.

## Exclusive Gateway ownership

- A same-user Gateway Agent remains idle until a Client acquires a lease, then owns one OpenOCD Gateway instance for either Live Monitor or Cortex-Debug.
- Leases are generation-bound and carry the authoritative loopback GDB/TCL binding. A stale Client cannot renew, release or reopen a prior Gateway binding.
- Heartbeat expiry, explicit Stop, process failure and malformed persisted lease data enter bounded cleanup or recovery paths. Clients close their tunnel, active session and UI ownership when a lease is no longer valid.

## Setup, diagnostics and packaging

- Gateway Quickstart now prepares both SSH and the Gateway Agent when invoked with `--confirm-system-change`.
- Windows uses the B300-owned `B300-STLink-GatewayAgent` Scheduled Task; Linux uses the B300-owned per-user systemd unit. The on-demand Agent ensure path remains available.
- Gateway request and response artifacts are size-bounded, replay-protected and cleaned up. Public diagnostic evidence omits lease tokens, credentials and user-bearing paths.

## Safety and validation

GDB and TCL remain bound to loopback, Telnet remains disabled, and the existing no-flash debug, Application/Factory programming, WRP and RDP safety policies are unchanged.

The release candidate has software/mock validation for exclusive ownership, endpoint propagation, stale-generation rejection, heartbeat-loss teardown, recovery, protocol and package behavior. It does not claim direct physical-board, IPC or cable-disconnect acceptance. `HW-P1-001` remains **OPEN / DEFERRED**.
