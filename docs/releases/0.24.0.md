# B300 ST-Link Tools v0.24.0

Release date: 2026-09-24

## Scope

v0.24.0 combines the repository-consolidation work after v0.23.2 with managed remote Application programming, isolated Ubuntu Gateway deployment, and the AMR Gateway/OpenOCD race-condition hardening.

## Main changes

- Canonical production GUI entry and extracted read-only CLI inspection commands with v0.23.2 functional-parity guardrails.
- Managed remote Application programming from Windows Client to an authenticated Gateway, including staged firmware upload, audited dry-run, explicit prepare/commit, reconnectable job history, and exclusive ST-Link ownership.
- Isolated Ubuntu Gateway control path using private runtime state and bounded ingress staging before remote programming is enabled.
- Gateway supervisor serialization and fault latching so USB/SWD/OpenOCD faults cannot publish or retain a false READY state across service generations.
- Improved packaged Linux host inspection and managed SSH connect-check behavior.

## Safety invariants

- Normal Application programming never mass-erases the MCU.
- Sector 0-2 Bootloader remains protected and is not written by the normal Application flow.
- Normal Application programming does not change RDP or WRP.
- Remote Debug remains loopback-only on the Gateway; GDB/TCL are not exposed directly to the LAN.
- Application programming keeps the canonical Sector 3-7 transaction and 44-byte STLM AppMeta verification before reset.
- Remote Bootloader provisioning remains local factory-only by policy.

## Release gates

Stable publication requires the exact release commit to pass source CI on Windows x64, Ubuntu x64, and Ubuntu ARM64, release packaging/smoke checks, and the current hardware acceptance checklist. Hardware evidence is recorded separately under `docs/acceptance/`.
