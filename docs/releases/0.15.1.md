# B300 ST-Link Tools v0.15.1

v0.15.1 is a focused UX consolidation release for remote Debug. It removes the duplicated SSH/Gateway workflow from the production navigation and makes Debug Studio the single place where the operator selects `LOCAL`, `GATEWAY`, or `CLIENT`.

## Unified Debug connection flow

- Debug Studio is now the single source of truth for connection roles: `LOCAL`, `GATEWAY`, and `CLIENT`.
- Removed the separate top-level **Cầu nối Từ xa (SSH)** entry from the production sidebar.
- Gateway host preparation remains available internally from the `GATEWAY` Debug flow through **CẤU HÌNH GATEWAY**.
- Client authentication remains only in the `CLIENT` Debug flow through one **ĐĂNG NHẬP SSH** action.
- The internal Gateway setup page no longer asks the operator to choose Gateway/Client again.
- Legacy public-key authorization controls are hidden from the normal v0.15.1 production workflow.

## Clearer engineering terminology

- Reworked the first Debug screen so each role explicitly describes where the ST-Link is connected and where the debugger runs.
- `LOCAL`: Debug trực tiếp qua ST-Link trên máy hiện tại.
- `GATEWAY`: Máy hiện tại cắm ST-Link và cung cấp Debug từ xa.
- `CLIENT`: Máy hiện tại Debug STM32 qua Gateway bằng SSH.
- Gateway start/stop controls remain compact and consistent with the existing Debug API.
- When the internal Gateway setup page is open, the visible navigation remains associated with **Studio Debug · Theo dõi**, avoiding the impression of a second independent subsystem.

## Compatibility and safety

- No change to Flash, OTA, Bootloader, metadata, Option Bytes, or normal provisioning policy.
- No change to the STM32F407 protected memory boundaries.
- No change to loopback-only GDB/TCL exposure policy.
- No change to zero-halt Live Monitor behavior.
- No new debugger memory-write capability is introduced.
- Existing legacy SSH/Gateway implementation remains available internally for compatibility, but it is no longer presented as a competing production workflow.

## Quality gate

- Added regression coverage for the unified production navigation and single Client SSH login surface.
- Version source is bumped to `0.15.1` and the release workflow continues to validate the source version against tag `v0.15.1` before packaging.
- Windows x64, Ubuntu x64, and Ubuntu ARM64 CI must pass before the release tag is created.

This patch is intentionally limited to connection hierarchy, naming, and production navigation so the v0.15.0 debugger backend and hardware-safety behavior remain stable.
