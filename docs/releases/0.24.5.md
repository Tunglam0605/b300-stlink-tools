# B300 ST-Link Tools v0.24.5

The native Pulse Dock now opens by default with **Debug** and **Nạp code**.
Debug uses one connection selector for local ST-Link or IPC/SSH and opens
VS Code automatically. Advanced production tools remain available through
Options. The debug connection is remembered across programming navigation.

Setup, project/profile selection, SSH, debug, canonical programming preflight
and cleanup use the real production backend. Serialized background operations
keep the GUI responsive; stale recovery callbacks cannot claim another session.
Launching VS Code from Codex no longer inherits Electron's Node mode, and
immediate launcher failures are surfaced.

This release builds on v0.24.4 and retains its verified-download acceleration,
Gateway fixes and remote-programming backend. The simple programming task stays
local; existing advanced programming workflows and bootloader protections are
preserved. The portable B300 agent skill documents the new GUI and managed
Gateway/SSH automation flow.
