The v0.11.0 GUI Debug Workspace change is presentation/state routing over already-tested GDB primitives; no new GDB primitive or breakpoint/watchpoint behavior was introduced.

## Deferred field gates before Stable publication

Stable tag/publication remains blocked by the project release policy until the following physical field gates are completed:

1. cold physical power-cycle acceptance;
2. full `OTA -> ST-Link -> OTA` interoperability sequence on hardware;
3. real two-machine SSH acceptance for GUI Client / CLI Client / VS Code-Cortex-Debug.

These are field/system acceptance tasks, not unresolved software unit/CI failures.
